# Security policy

## Supported versions

Security fixes are applied to the latest released version and the `main`
branch.

## Reporting a vulnerability

Please report privately to the repository owner using GitHub's private
security-advisory reporting feature. If that feature is unavailable, contact
the maintainer through the repository profile and include only the minimum
information needed to establish a secure channel.

Do not include secrets or working exploit payloads in a public issue. Useful
reports explain the affected version, impact, reproduction conditions, and
whether the issue could execute a command, bypass a read-only refusal, expose
credentials, or alter adapter/install behavior.

We will acknowledge a report, assess its scope, and coordinate a fix before
public disclosure where practical.
